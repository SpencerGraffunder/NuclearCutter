▚ SCAN

LLM :8080 · whisper :8081
Bearer token for the model server (Strata and other key-protected backends reject unauthenticated scans). Saved with your settings.
Loaded on demand when a scan transcribes (the server hot-swaps to it first; the one marked (loaded) is the one currently active).
The sweep is the full-film pass that dominates scan time. It answers the coarse "anything here?" question, so it can view fewer pixels than the detailed identify pass (always full scale). Check accuracy with Benchmark before a long scan.
Separate, larger model served by the same backend (pick it via “Scan for models”). Used for the optional blur/black-card text (“Better blur text”) and the captions shown while audio is muted — never for the scan itself.
Assumed loaded context if the server doesn't report one. A warning shows when the prompt may exceed it.

▚ WHAT TO CENSOR

The scan records what is in the film; this is what you want hidden. Nothing is ticked by default — tick the categories that matter to you, per movie or once for your household. Hover any category to read exactly what it means.
Spend one call per CENSORED segment rewriting its blur/black-card text with the summary model above. Off by default: the scan already stores a short description of every segment, and paying for the whole film when you censor two minutes of it is a bad trade.
