Bearer token for the model server (Strata and other key-protected backends reject unauthenticated scans). Saved with your settings.
Loaded on demand when a scan transcribes (the server hot-swaps to it first; the one marked (loaded) is the one currently active).
The sweep is the full-film pass that dominates scan time. It answers the coarse "anything here?" question, so it can view fewer pixels than the detailed confirm pass (always full scale). Check accuracy with Benchmark before a long scan.
Separate, larger model that rewrites every visual detection's on-screen text (frames + transcript) right after the scan, and flags them all on the timeline. Served by the same backend — pick it from the list via “Scan for models”.
Assumed loaded context if the server doesn't report one. A warning shows when the prompt may exceed it.
