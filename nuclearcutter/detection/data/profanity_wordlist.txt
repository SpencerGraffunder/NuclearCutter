# Default profanity wordlist for NuclearCutter.
# One word (or short phrase) per line, lowercase. Lines starting with # are
# ignored, and surrounding whitespace is stripped, so this file is safe to edit
# by hand.
#
# This is a TRIGGER list, not a verdict. Every match is re-checked in context by
# an LLM (see nuclearcutter/detection/language.py), which decides WHICH category
# the line belongs to — "ass" inside "assassin", "hell" in "hell no", and a slur
# quoted to condemn it are all rejected there. So being broad here is cheap and
# being narrow is expensive: a word missing from this file can only be caught by
# the dialogue sweep's judgement, never by a rule.
#
# The section headings are a reading order only. They do not decide the tag: the
# LLM's answer does, so a "mild" word used as a weapon is still tagged as the
# insult it was, and a severe word used clinically may be tagged as anatomy.
